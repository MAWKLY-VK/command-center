# A curated hybrid map library, without scraping

The library holds 50 to 150 maps: Generals Online's competitive maps plus classics, each with `author` and `source`.
For everything else it links to AODMaps, CNC Labs and ModDB. Command Center also watches the Downloads folder and
extracts ZIP, RAR and 7z archives safely. No website is scraped.

The old `zh-map-library` stays online, because existing copies read it. The user deletes it by hand only after no
copy reads it any more.

Decided with the user on 2026-11-04 (plan appendix B, phases 1 and 5).
