# Stay a companion to the official Generals Online launcher, Generals Online first

Command Center starts the game the way Generals Online's launcher does and adds tools around it. It never replaces
that launcher, never changes Generals Online's program files, and never decides its updates or its anti-cheat.
Generals Online owns the client, its updates and its anti-cheat, so a replacement would have to follow every change
they make.

The scope is Generals Online first. Seams for later work are built as structure only: several installations, mods
through hard links, per-mod profiles and the TheSuperHackers client.

Decided with the user on 2026-11-04 (plan appendix B, phase 1).
