# Changelog

## 0.1.0 – first test build

- Home, Maps, Replays, Hotkeys, Health, Add-ons and Settings pages.
- Hotkey editor reads Generals Online's community patch, orders teams 1–9 then 0 and checks the engine's key rules.
- Health checks for wrapper and Visual C++ DLLs, error 740, compatibility modes, rule-changing archives and more, each fix with Undo.
- Map library with start positions from the game's map cache.
- Replay browser with armies, teams, watch, keep, rename, star and delete with Undo.
- Control Bar Pro (five sizes) and Observer bar with pinned checksums.
- Layout tested at 1280 × 720 and 1600 × 1000.
